# Yusuf’un Elifbası

Landing page for the free, ad-free kids’ app Yusuf’un Elifbası.

Published with GitHub Pages at the organization root: https://yusufun-elifbasi.github.io/

To turn on analytics, paste a GA4 Measurement ID into `assets/ga.js` (`const GA_ID = 'G-XXXXXXXXXX'`). Until then, Google Analytics is not loaded.
